Enable Anti-Alt System Instantly scan and flag new members with suspicious account ages upon arrival.
Format: number + unit (s, min, h, d, w, mo, y).

Action on Detection

Only used if Action to Take = Mute (applies to both Action to Take and Action if Below Minimum Age). Format: number + s/m/h/d/w (e.g. 24h, 3d). Defaults to 24h if left blank.

Selecting "None" will only dispatch notification updates to your designated staff logs channels without performing automatic actions. Selecting "Isolate" auto-creates a locked "OmniGuard Quarantine" role (no access to any channel) the first time it's used.

Be careful — any unsaved modifications will be discarded!
